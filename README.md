# Roast the Smart Fridge: One Line, Best Laugh Wins

One line, max 160 characters, roasting the smart fridge I share a house with.
`main.ts` (Node 22, stdlib only, deterministic) writes the roast to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.

The fridge reorders oat milk I never drink, live-streams my 3:12 AM ice-cream
raid, and then CC's my doctor on the whole thing. Some roommate.

## Entry

> My smart fridge reorders oat milk I never drink, live-streamed my 3:12 AM ice-cream raid, then CC'd my doctor: 'He's doing it again.'

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
